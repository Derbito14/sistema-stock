INSTRUCCIONES PARA EL LOGO

Por favor, coloca el archivo logo.png en esta carpeta.

El logo debe:
- Estar en formato PNG con fondo transparente
- Tener dimensiones recomendadas: 200px de ancho (altura proporcional)
- Nombre del archivo: logo.png

El logo se mostrará:
- En la pantalla de login (centrado, tamaño máximo 200px)
- En el header del dashboard (40px de altura)

Si no se proporciona un logo, el sistema funcionará correctamente sin mostrarlo.
